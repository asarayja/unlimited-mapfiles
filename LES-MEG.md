# Unlimited kartpakke (2026-11-04)

Åpne `index.html` via en webserver (f.eks. GitHub Pages) for å teste. Fra disk virker den ikke i alle nettlesere.

## Lag (alle zoom 0–7, 256 px, samme projeksjon som Unlimited)
- `tiles/atlas_cayo/`     – GTA + Cayo kart (uendret kopi av det gamle kartet)
- `tiles/postal_02/`      – postkoder for GTA, rettet etter postal.psd: 1 687 koder, ingen doble
- `tiles/postal_roxwood/` – postkoder for Roxwood, eget lag (vises bare når Roxwood er på)
    - 770–999: fra map_postals (gammel Roxwood-postkart), 229 koder (820 fantes ikke)
    - 300–591: nye koder for resten av Roxwood (utkast, 292 koder)
- `tiles/roxwood/`        – Roxwood-spillkartet (fra Extra Map Tiles-ressursen)

## Kreditering
